## Məzmun

### Praktik AI 1-ci hissə: [YouTube videosu](https://www.youtube.com/watch?v=Y3BaTG-ctvU)

- Materiallar: `CyberAZE/Practical AI/Part 1/`

Hər təqdimat ayrıca qovluqda təşkil olunub. Materiallara prezentasiya faylları, demo kodları və sessiya zamanı istifadə olunan kiçik təcrübələr daxil ola bilər.

## İstifadə

Lazımi materiallara baxmaq üçün uyğun təqdimat qovluğunu açın. Requirement-lər yükləndikdən Python nümunələrini uyğun lokal Python mühitində işə sala bilərsiniz.
